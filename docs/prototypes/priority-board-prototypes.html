Priority Board Study

Tighter surfaces, clearer type, one category signal.

These prototypes keep the board calm and dense, but fix the current weak spots: the column trays have stronger edge definition, the cards feel carved rather than flat, title and category contrast are much clearer, and each direction removes the duplicate left-bar plus dot combination in favor of a single category indicator.

What changed across all three

  • Column surfaces now use a restrained inset frame and deeper floor shadow so the layout reads cleanly without getting glossy.
  • Card depth is built from tight inner highlights plus a very short outer lift, instead of relying on a bright border or muddy glow.
  • Category text sits closer to secondary contrast, not tertiary, so it stays readable at a glance in a dense board.
  • Count pills and headers are sharper and more intentional, with better micro-contrast and less visual fuzz.

My recommendation

Prototype B feels closest to an OpenAI-like product surface: the cards stay neutral and clean, while the category chip carries the only color cue. It removes the strip noise that builds up in long columns, but still keeps categories obvious.

Tradeoff Summary

The three original directions are still useful, but these `C` variants and light studies are probably closer to where you want to land if the count badge is the north star.

C1: Whisper Frame Best if you want the quietest board possible. Very elegant, but it risks feeling a touch too soft once a column fills up.
C2: Inset Frame Best balance overall. This is the strongest translation of the count badge language onto the full rectangle, and it keeps the board crisp without shouting.
C3: Lifted Slate Best if you want the cards to feel more premium and tactile. It has more object-ness, but it is the easiest one to overdo.
